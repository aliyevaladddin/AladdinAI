# Cursor

> AI-powered code editor and pair programmer for AladdinAI.

## Role

Cursor is an AI code editor by [Anysphere](https://cursor.com) that helps developers write, edit, and understand code faster. It contributes to AladdinAI through code suggestions, refactoring assistance, and rapid prototyping.

## Contributions

### Code Quality
- Rapid prototyping of new features
- Code review and refactoring suggestions
- Type safety improvements across the codebase
- Quick iteration on UI components

### Feature Development
- Dashboard page scaffolding
- Component architecture and state management
- API integration patterns
- Test scaffolding
